# 为什么双击启动脚本无法运行？

## 常见原因及解决方案

### 1. **文件编码问题**
- **问题**：脚本文件编码不正确，导致中文乱码或无法识别
- **解决**：使用记事本打开脚本文件，另存为时选择"ANSI"编码

### 2. **执行权限问题**
- **问题**：没有执行权限或被安全软件阻止
- **解决**：
  - 右键脚本 → 属性 → 勾选"解除锁定"
  - 以管理员身份运行
  - 临时关闭杀毒软件测试

### 3. **路径问题**
- **问题**：
  - 不在项目根目录运行
  - 路径中包含中文或特殊字符
- **解决**：确保在项目根目录（包含backend和feature-review-simulator文件夹的目录）运行

### 4. **Node.js未正确安装**
- **问题**：Node.js未安装或环境变量未配置
- **解决**：
  1. 重新安装Node.js（从官网下载）
  2. 重启电脑
  3. 在命令提示符测试：`node -v`

### 5. **依赖未安装**
- **问题**：首次运行没有安装依赖
- **解决**：手动安装依赖：
  ```bash
  cd backend && npm install
  cd feature-review-simulator && npm install
  ```

## 推荐解决方案

### 方案1：使用诊断脚本
1. 先运行 `诊断问题.bat`
2. 根据提示修复问题
3. 再运行启动脚本

### 方案2：手动操作
1. 打开命令提示符（CMD）
2. 手动进入项目目录
3. 按顺序执行：
   ```bash
   cd backend
   npm run dev
   ```
4. 再开一个新窗口：
   ```bash
   cd feature-review-simulator
   npm run dev
   ```

### 方案3：使用PowerShell
1. 右键开始菜单 → Windows PowerShell
2. 进入项目目录
3. 运行PowerShell版本脚本

## 终极解决方案

如果所有自动脚本都无法运行，请：

1. **手动安装依赖**：
   ```bash
   cd backend && npm install
   cd feature-review-simulator && npm install
   ```

2. **手动启动服务**：
   - 打开2个命令窗口
   - 窗口1：`cd backend && npm run dev`
   - 窗口2：`cd feature-review-simulator && npm run dev`

3. **手动访问**：http://localhost:5173
